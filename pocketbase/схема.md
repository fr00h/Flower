# Схема базы данных «Цветочный магазин»

Коллекции создаёт скрипт `setup.mjs`, он же заливает тестовые данные и учётные записи.
Поля `id`, `created`, `updated` PocketBase добавляет сам.

## users - учётные записи (встроенная коллекция)

| Поле | Тип | Настройки |
| --- | --- | --- |
| email | Email | обязательное, уникальное |
| name | Plain text | имя |
| role | Select | обязательное: `customer`, `florist`, `admin` |

## categories - категории букетов

| Поле | Тип | Настройки |
| --- | --- | --- |
| name | Plain text | обязательное, 2-50, уникальное |
| description | Plain text | до 300 |

## flowers - цветы

| Поле | Тип | Настройки |
| --- | --- | --- |
| name | Plain text | обязательное, 2-50 |
| color | Plain text | до 30 |
| price | Number | обязательное, 1-10000 |
| stock | Number | целое, 0-100000 |

## bouquets - букеты

| Поле | Тип | Настройки |
| --- | --- | --- |
| name | Plain text | обязательное, 2-100 |
| category | Relation → categories | обязательное, одна запись |
| price | Number | обязательное, 1-100000 |
| description | Plain text | до 500 |
| available | Bool | |

## bouquet_items - состав букета (многие ко многим букеты ↔ цветы)

| Поле | Тип | Настройки |
| --- | --- | --- |
| bouquet | Relation → bouquets | обязательное, каскадное удаление |
| flower | Relation → flowers | обязательное |
| quantity | Number | обязательное, целое, 1-101 |

Уникальный индекс (bouquet, flower).

## suppliers - поставщики

| Поле | Тип | Настройки |
| --- | --- | --- |
| name | Plain text | обязательное, 2-100 |
| phone | Plain text | шаблон `+7 900 123-45-67` |
| email | Email | |
| city | Plain text | до 50 |

## supplies - поставки

| Поле | Тип | Настройки |
| --- | --- | --- |
| supplier | Relation → suppliers | обязательное |
| flower | Relation → flowers | обязательное |
| quantity | Number | обязательное, целое, 1-10000 |
| price | Number | обязательное, 1-10000 |
| supplied_at | Date | обязательное |

## cards - карты покупателей (один к одному с users)

| Поле | Тип | Настройки |
| --- | --- | --- |
| user | Relation → users | обязательное, уникальное, каскадное удаление |
| number | Plain text | обязательное, уникальное, шаблон `FC-000001` |
| discount | Number | целое, 0-30 |

## orders - заказы

| Поле | Тип | Настройки |
| --- | --- | --- |
| user | Relation → users | обязательное |
| status | Select | `new`, `assembling`, `delivering`, `done`, `canceled` |
| total | Number | сумма со скидкой |
| comment | Plain text | до 300 |
| created, updated | Autodate | |

## order_items - позиции заказа (многие ко многим заказы ↔ букеты)

| Поле | Тип | Настройки |
| --- | --- | --- |
| order | Relation → orders | обязательное, каскадное удаление |
| bouquet | Relation → bouquets | обязательное |
| quantity | Number | обязательное, целое, 1-50 |
| price | Number | цена букета на момент заказа |

## deliveries - доставка (один к одному с orders)

| Поле | Тип | Настройки |
| --- | --- | --- |
| order | Relation → orders | обязательное, уникальное, каскадное удаление |
| address | Plain text | обязательное, 5-200 |
| date | Date | обязательное |
| time_slot | Select | `10-14`, `14-18`, `18-22` |
| recipient | Plain text | обязательное, 2-100 |
| phone | Plain text | обязательное, шаблон телефона |

## Правила доступа

| Коллекция | Смотреть | Создавать | Менять | Удалять |
| --- | --- | --- | --- | --- |
| categories, flowers, bouquets, bouquet_items | все | флорист, админ | флорист, админ | флорист, админ |
| suppliers, supplies | админ | админ | админ | админ |
| cards | владелец, админ | админ | админ | админ |
| orders | владелец, флорист, админ | сам покупатель, статус new | флорист, админ | админ |
| order_items, deliveries | владелец заказа, флорист, админ | владелец нового заказа | админ / флорист, админ | админ |
| users | сам, флорист, админ | все, только роль customer | сам без роли, админ | админ |
